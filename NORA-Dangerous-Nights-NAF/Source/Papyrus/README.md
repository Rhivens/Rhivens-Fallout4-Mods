# Papyrus Sources

This folder contains the public Papyrus source files for **NORA Dangerous Nights - NAF 0.18 RC1**.

## Included sources

- `RHI_NDN_Controller.psc` — sleep detection, location and Pervert probability rolls, one-to-three-attacker encounters, dialogue/camera handling, Submit/Resist logic, NAFBridge and AAF Violate events, and engine-safe cleanup.
- `RHI_NDN_MCM.psc` — synchronization between the JSON MCM settings and the plugin's GlobalVariables.
- `TIF_RHI_NDN_ControllerQuest_0100001F.psc` — TopicInfo fragment for **Submit**.
- `TIF_RHI_NDN_ControllerQuest_01000021.psc` — TopicInfo fragment for **Resist**.

## Compilation dependencies

The controller imports or references APIs supplied by the installed modding environment, notably NAFBridge/AAF-compatible API sources, AAF Violate's `FPV_OnHit`, MCM, Workshop framework sources and `LL_FourPlay` for the external message INI.

Pervert is deliberately accessed dynamically with `Game.GetFormFromFile`, `CastAs` and `CallFunction`. Its script is not required to compile NORA NDN and `pervert.esp` is not a master.

## TopicInfo fragments

The two `TIF_...` filenames are generated by the Creation Kit and contain FormID-derived identifiers. If the plugin is rebuilt, identify each fragment by its TopicInfo/dialogue branch rather than relying only on the generated filename.

Compiled `.pex` files are distributed with the mod package. Development experiments, backups and obsolete revisions remain outside the public repository.

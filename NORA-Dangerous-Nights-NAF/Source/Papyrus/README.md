# Papyrus Sources

This folder contains the public Papyrus source files for **NORA Dangerous Nights - NAF**.

## Included sources

- `RHI_NDN_Controller.psc` — main encounter controller, sleep detection, location-based chance roll, attacker spawning, Submit/Resist handling, NAFBridge scene events, AAF Violate integration and cleanup logic.
- `RHI_NDN_MCM.psc` — MCM settings synchronization with the mod's GlobalVariables.
- `TIF_RHI_NDN_ControllerQuest_0100001F.psc` — TopicInfo fragment used by the **Submit** branch.
- `TIF_RHI_NDN_ControllerQuest_01000021.psc` — TopicInfo fragment used by the **Resist** branch.

## Notes

The two `TIF_...` filenames are generated by the Creation Kit and contain FormID-derived identifiers. Their exact filenames may change if the plugin is rebuilt or FormIDs are compacted again. Identify them by the TopicInfo / dialogue branch they belong to rather than relying only on the generated filename.

These are the source files corresponding to the current public release preparation. Compiled `.pex` files are distributed with the mod itself.

Development notes, experiments, backups and obsolete script revisions remain outside the public repository.

For permissions regarding modification, reuse, forks and translations, see the repository-wide **Modding & Permissions** section on the main page.

# Traduction française

Ce dossier documente la traduction française séparée de **NORA Dangerous Nights - NAF 0.18 RC1**.

Le mod principal reste développé en anglais afin de faciliter la maintenance dans le Creation Kit et la création d'autres traductions.

La traduction française distribuée séparément remplace uniquement les éléments linguistiques nécessaires :

- l'interface JSON du MCM ;
- les messages narratifs de `RHI_NDN_messages.ini` ;
- les chaînes visibles et les diagnostics des scripts compilés ;
- les textes du plugin lorsque nécessaire.

Elle requiert toujours l'installation du mod principal correspondant à la même version. Les identifiants techniques, noms d'événements, clés MCM et appels d'API ne doivent pas être traduits.

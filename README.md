# Rhivens — Fallout 4 Mods

Welcome to my public Fallout 4 modding repository.

This repository contains the mods, patches, translations and related documentation that I choose to share publicly with the Fallout 4 community.

Most projects here are created and tested in a heavily modded **Fallout 4 OldGen 1.10.163** environment, with a focus on compatibility, lightweight implementation and practical gameplay improvements.

---

## Published Mods

### NORA Dangerous Nights - NAF

A lightweight NAF-based wake-up encounter mod inspired by the general concept of *Dangerous Nights*, but built as an independent project without using the original plugin as a master.

Main features include:

- location-based encounter chances after sleeping;
- random attacker selection;
- Submit / Resist dialogue choices;
- direct NAF scene handling through NAFBridge;
- combat / escape / defeat branches;
- clean attacker removal after the encounter;
- MCM configuration;
- separate French translation.

**Status:** preparing public release.

Project folder: `NORA-Dangerous-Nights-NAF/`

## Compatibility Philosophy

I try to keep my mods as self-contained and lightweight as possible.

When a dependency is required, it will be clearly listed in the mod documentation. Optional integrations and known compatibility issues will also be documented whenever they are known.

Because Fallout 4 mod setups can vary enormously, compatibility can never be guaranteed with every possible load order.

---

## Languages

Development is generally done in **English** for Creation Kit and scripting stability.

When available, **French translations** are provided separately so that the original plugin remains easy to maintain and can also be translated into other languages.
